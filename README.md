# FraudLens AI

Unified cyber fraud analysis.

Workflow: Upload evidence on `/` → SHA-256 + Evidence ID → parse/normalize (browser) → case handed to `/dashboard` → staged loader (correlate → score → chain) → analysis summary → graph + timeline → JSON / PDF / manifest export.

## Run locally

```bash
npm install
npm run dev
# open http://localhost:3000
# → download and manually upload the four sample files
# → open the dashboard and review the analysis
```

Demo case `CASE-001: Rapid Mule Account Routing` loads a larger deterministic synthetic dataset:
- 120 CDR records, 120 IPDR sessions, 100 bank transactions, and 80 device records
- shared IMEI `356789012345678` (conf 1.00)
- shared IP `103.21.45.10` close-window (conf 0.75, contextual only)
- chain `VICTIM-001 → MULE-001 → MULE-002 → CASHOUT-001`
- High or critical risk with reasons, timeline, JSON + PDF exports

The larger files are generated by `node scripts/generate-synthetic-data.mjs` and stored in
`public/samples/`. They contain fictional identifiers only.

Sample files: `public/samples/`.

## Analysis summary service

Deterministic rules run first; the analysis summary adds an officer-ready narrative.

```bash
cp .env.example .env.local
# add GROQ_API_KEY=gsk_... (get one at console.groq.com)
npm run dev
# Dashboard → Generate analysis
```

Optional: `GROQ_MODEL` (default `llama-3.1-8b-instant`, with automatic fallback if Groq retires it). Without a key the panel shows setup steps and everything else still works. Only normalized findings go to Groq - never raw files. Key stays server-side (`/api/insights`).

## Deploy to Vercel

1. Push this folder to GitHub.
2. Vercel → New Project → import repo (framework: Next.js).
3. Project → Settings → Environment Variables → add `GROQ_API_KEY` (+ optional `GROQ_MODEL`).
4. Deploy and test: open deployment → download and manually upload the four sample files → Evidence → Dashboard → Generate analysis → Export.

Notes: browser-side hashing/parsing keeps payloads <4.5MB; no DB/auth; no evidence stored server-side; full phone/account numbers never logged.
